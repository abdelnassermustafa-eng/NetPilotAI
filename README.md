# NetPilotAI

### AI-Powered Infrastructure Operations Platform

NetPilotAI is an AI-assisted infrastructure operations, observability, and AWS network intelligence platform designed to provide engineers with real-time visibility into cloud infrastructure, operational state, and network topology.

The platform combines AWS network discovery, observability, operational dashboards, infrastructure validation, and automation workflows into a single operational interface focused on safety, visibility, and correctness.

## Core Capabilities

* AWS Infrastructure Visibility
* Network Topology & Routing Analysis
* Observability (Logs, Metrics, Alerts, Events)
* Infrastructure Validation
* Operational Dashboards
* Automation Frameworks
* AI-Assisted Operations
* Read-Only Safe Operations Model

## Technology Stack

* Python
* FastAPI
* AWS APIs
* SQLite
* Tailwind CSS
* Alpine.js
* REST APIs
* Infrastructure Automation

## Project Vision

NetPilotAI aims to evolve into a production-grade Infrastructure Operations Platform capable of combining cloud infrastructure visibility, observability, automation, validation, and AI-assisted operational decision making.
